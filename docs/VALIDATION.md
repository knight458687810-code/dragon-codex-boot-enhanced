# 验证范围（公开摘要）

本版沿用并扩展了原项目测试。发布前在本地 Windows 环境重新构建，执行配置/几何/交互/窗口就绪断言，以及隔离快捷方式安装/恢复测试；`--self-test` 覆盖 605 项几何情况和 12 项固定放置情况。自动化测试不打开真实 Codex，不代表跨机器完整验收。

## 性能记录的解释

三轮关闭 Start 交互的隔离播放，整机平均 CPU 约0.140% /0.149% /0.164%，峰值工作集约332 /362 /336 MiB。早前完整交互生命周期样本约18.5秒，整机平均 CPU 约0.121%，峰值工作集约556 MiB；两者模式不同，不应混为一谈。

数据来自单台机器，未测 Codex P95 帧时间或 GPU 竞争，不能据此承诺零影响。交接后进程退出，资源不是常驻开销。公开仓库只保留不含本机信息的摘要，不打包私人运行日志或快捷方式备份。

## 建议的手动验收

1. 普通窗口、最大化、最小化各启动一次，核对视频完整等比、遮罩只覆盖目标客户区。
2. 主/副显示器、不同 DPI、负坐标布局各测试一次。
3. 点 X 关闭窗口但保留进程，再从动画入口打开，核对新/隐藏窗口跟随。
4. Start 暂停时悬停、移出、按下移出、点击；确认继续播放且音轨不提前播放。
5. 准备、暂停、播放、交接阶段分别 Esc，确认只跳过动画并正常交接。
6. 任务管理器确认交接后启动器退出；常用操作的流畅度与不运行启动器的基线对比。
